Ubuntu / Linux

Fcitx5 ile gerçek input method kurulumu

Linux tarafında hook kullanmıyoruz. BulgarianIME doğrudan Fcitx5 addon olarak yüklenir. Bu yüzden uygulamalarla entegrasyon Linux'un kendi input-method sistemi üzerinden gerçekleşir.

01

Gerekli paketleri kur

sudo apt update
sudo apt install fcitx5 fcitx5-config-qt libfcitx5core-dev build-essential cmake ninja-build pkg-config
02

Projeyi derle

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target bulgarianime

CLion kullanıyorsan target olarak bulgarianime seç. Bu bir exe değildir; Fcitx5'in yüklediği .so addon'dur.

03

Addon'u sisteme kur

sudo cmake --install build
fcitx5 -rd
04

Input method listesine ekle

fcitx5-configtool

Only Show Current Language işaretini kaldır. BulgarianIME ara ve aktif input method listene ekle.

05

Fcitx5'i oturumun input method'u yap

im-config

Gerekliyse listeden fcitx5 seç. Ardından oturumu kapatıp aç veya reboot et.

06

Firefox çalışmıyorsa önce reboot

Addon Fcitx5 içinde çalışıp Firefox veya diğer masaüstü uygulamalarında çalışmıyorsa ilk yapacağın şey:

reboot

Bizim Ubuntu kurulumunda uygulama entegrasyonunu tamamlayan adım reboot oldu.

Linux sorun giderme

Kurulum sırasında karşılaştığımız gerçek problemler.

Bir şey ters giderse büyük ihtimalle aşağıdakilerden biridir.

“Could not locate library bulgarianime.so”+

Fcitx addon tanımını görüyor ama derlenen bulgarianime.so doğru addon dizininde değil demektir.

SRC=$(find ~/Downloads -type f -name 'bulgarianime.so' -print -quit)
LIBDIR=$(pkg-config --variable=libdir Fcitx5Core)
ADDON_DIR="$LIBDIR/fcitx5"

echo "$SRC"
echo "$ADDON_DIR"

Dosyayı doğru yere kur:

sudo install -m755 "$SRC" "$ADDON_DIR/bulgarianime.so"
fcitx5 -rd

Başarılı yüklemede logda:

Loaded addon bulgarianime
BulgarianIME listede görünmüyor+

fcitx5-configtool içinde Only Show Current Language seçeneğini kapat ve tekrar ara.

find /usr -iname '*bulgarianime*' 2>/dev/null
Fcitx5 içinde çalışıyor, Firefox'ta çalışmıyor+

Önce reboot et. Oturum değişkenleri ve frontend entegrasyonu yeni oturumda doğru şekilde yüklenebilir.

reboot

Hâlâ çalışmazsa im-config ile Fcitx5'in seçildiğini doğrula.

“Failed to open wayland connection” görüyorum+

X11 oturumundaysan bu mesaj tek başına hata değildir. Aynı logda X11'e bağlanıldığını ve sonunda Loaded addon bulgarianime görüyor olabilirsin.

echo $XDG_SESSION_TYPE
CLion'da hangi target?+

Linux için bulgarianime target'ını build et. Run etmeye çalışma. bgime-cli yalnızca terminal testi içindir.

Daha ayrıntılı teşhis+
fcitx5-diagnose

Frontend, input method ve ortam yapılandırmasıyla ilgili bilgileri toplar.
