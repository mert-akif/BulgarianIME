Why BulgarianIME?

Daily use without learning a new keyboard layout.

Designed to stay simple for notes, messaging, browsers, and everyday text input.

⌨

Familiar keys

Uses natural transliteration such as sh → ш, ch → ч, and sht → щ.

TR

Turkish-Q friendly

Includes fast mappings such as ş → ш, ç → ч, j → ж, ı → ъ, and şt → щ.

↯

Streaming engine

Does not buffer the whole word. Only the short ambiguous suffix that may still change is kept temporarily.

∞

Windows + Linux

A lightweight global hook on Windows and the native Fcitx5 input-method framework on Linux.

Windows

Windows usage

  1. 1

    Download the release package

    Download the Windows x64 package from GitHub Releases and extract the archive.

  2. 2

    Run BulgarianIME.exe

    The app processes keyboard input in the background. You can use it in normal text fields such as Notepad, WhatsApp, Discord, and browsers.

  3. 3

    Shortcuts

    Ctrl + Alt + BEnable / disable
    Ctrl + Alt + QExit the app
About the Windows version

The current Windows version uses a global keyboard hook and synthetic input instead of a native TSF IME. Keep it disabled in password fields, anti-cheat protected games, and security-sensitive applications.

Ubuntu / Linux

Native input method setup with Fcitx5

On Linux, BulgarianIME does not use the Windows-style hook approach. It is installed directly as an Fcitx5 addon, which integrates more naturally with the Linux desktop.

01

Install the required packages

sudo apt update
sudo apt install fcitx5 fcitx5-config-qt libfcitx5core-dev build-essential cmake ninja-build pkg-config
02

Build the project

From the repository root:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target bulgarianime

If you use CLion, select the bulgarianime target. It is not a normal executable; it is a .so addon loaded by Fcitx5.

03

Install the addon

sudo cmake --install build

Then restart Fcitx5:

fcitx5 -rd
04

Add BulgarianIME to the input method list

fcitx5-configtool

Disable Only Show Current Language, search for BulgarianIME, and add it to your active input methods.

05

Set Fcitx5 as the session input method

If Fcitx5 is not currently configured system-wide:

im-config

Select fcitx5, then log out and back in or reboot the system.

06

A reboot can actually matter

If the addon works inside the Fcitx5 configuration UI but not in normal applications such as Firefox, reboot first.

reboot

On our Ubuntu setup, this was the step that completed integration with Firefox and other applications.

Linux troubleshooting

Real problems we encountered during setup.

If something goes wrong, it is likely one of the cases below.

Fcitx5: “Could not locate library bulgarianime.so”+

The addon definition was found, but the compiled bulgarianime.so is not in the Fcitx5 addon directory.

First, locate the compiled file:

SRC=$(find ~/Downloads -type f -name 'bulgarianime.so' -print -quit)
echo "$SRC"

Find the actual Fcitx5 library directory using pkg-config:

LIBDIR=$(pkg-config --variable=libdir Fcitx5Core)
ADDON_DIR="$LIBDIR/fcitx5"
echo "$ADDON_DIR"

Then install the addon into the correct directory:

sudo install -m755 "$SRC" "$ADDON_DIR/bulgarianime.so"
fcitx5 -rd

When it works, the Fcitx log should contain:

Loaded addon bulgarianime
BulgarianIME appears in Fcitx5 but does not work in Firefox+

Try a reboot first. Fcitx5 input-method environment settings may need a fresh desktop session.

reboot

If it still does not work, verify with im-config that Fcitx5 is selected.

BulgarianIME does not appear in the Fcitx5 input method list+

Open fcitx5-configtool, disable Only Show Current Language, then search for BulgarianIME.

If it still does not appear, check the installed files:

find /usr -iname '*bulgarianime*' 2>/dev/null
I see “Failed to open wayland connection”+

If you are using an X11 session, this line alone does not mean BulgarianIME is broken. If the log shows Connecting to X11 display and later Loaded addon bulgarianime, the addon is loaded.

To check your session type:

echo $XDG_SESSION_TYPE
Which CLion target should I use?+

On Linux, you build the bulgarianime target; you do not run it like a normal executable. The output is a shared library loaded by Fcitx5.

bgime-cli is only for testing the transliteration engine in a terminal.

How can I diagnose Fcitx5 in more detail?+ 
fcitx5-diagnose

This output is useful for diagnosing frontend, environment-variable, and input-method configuration problems.

How does it work?

A streaming design that does not rewrite the whole word.

1 Key Latin / Turkish-Q input
→
2 C++ Core Mapping + Composer
→
3A Windows Global hook
3B Linux Fcitx5 preedit / commit

The old approach could keep the entire word until Space or Enter and rewrite it whenever a new character arrived. The current engine only keeps a short ambiguous suffix that may still change, such as s, sh, z, c, or y. Characters are committed as soon as they become unambiguous.
